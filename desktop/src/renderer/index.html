链路恢复

已连接
断链 / 未自启 排查步骤
  1. 先点上面的「立即重连」（跳过 2s 退避，立刻重试一次）
  2. 船端服务是否在跑： systemctl is-active usv-edge
  3. 未启动则拉起： systemctl start usv-edge
  4. 启动失败看原因： journalctl -u usv-edge -b -n 30 --no-pager
  5. 开机自启是否还在： systemctl is-enabled usv-edge（应为 enabled）
  6. 端口是否被旧服务占用： ss -lntp | grep 9527
  7. 仍未恢复则整机重启： systemctl reboot

提示：每条命令点一下即可复制；目标地址见顶部「链路」胶囊。
